# Jagan Rao — Portfolio

Top-class personal portfolio for **React UI**, **Generative AI**, and **Claude**-powered product work.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons

## Run

```bash
cd /Users/jaganrao/Projects/portfolio
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit content in `src/data/content.ts` — name, projects, skills, services, experience, and contact details.
